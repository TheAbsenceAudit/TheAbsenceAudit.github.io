基础设施

翻译系统

v1 — 将研究记录译为法语、中文与俄语的闭环系统。每一个单元均由我们自有的流水线进行翻译，经度量验证，并予以修复或隔离。未经闭环审核通过的内容一律不得发布。

闭环

每个页面被拆分为具有稳定标识符的单元，且每个单元都会经过相同的六个站点：

1. 提取— 页面被切分为若干单元；每个单元保留其所属的标记代码。

2. 保护— 在翻译前对数字、DOI、URL、化学标识符及标记代码进行遮蔽。翻译可能会调整语序，但这些不变量必须保证字节级别的一致，且数字格式需完成本地化（法语和俄语使用小数逗号，中文采用西方格式）。

3. 翻译— 基于锁定的术语库对单元进行翻译。领域术语、UI词汇和产品名称针对每种语言一次性固化，随后强制应用于每个单元。

4. 验证— 包含四个关卡，详见下文。

5. 修复— 未通过的单元将附带审核人员的具体评审意见进行重新翻译，重试次数设有上限。

The four gates

Integrity.Every masked invariant must return byte-identical. A lost DOI, a changed number or an invented placeholder fails the unit.

Glossary lock.Every locked term present in the source must appear as its locked translation. The machine cannot silently reword a term — it fails the gate.

Reverse-translation review.The translation is translated back into English and scored against the original on four axes: meaning, terminology, completeness and register. A unit that fails the pass mark goes back through the loop with the reviewer’s criticisms.

Script check.The output must actually be in the target language — a Chinese or Russian page that is still mostly Latin text fails.

What the loop is sovereign over

Data.The research record never leaves this machine except as calls to our own model account. No translation agency, no platform and no freelancer ever holds a copy of the corpus, the glossary or a single translated sentence. The glossary and the translation memory are plain files in our source tree — assets we own outright.

Authority.Terminology is locked by us and enforced mechanically. The definition of “correct” is our glossary and our review rubric, not a vendor’s defaults.

Verification.Quality is proven by measurement — mechanical gates on everything, a review pass on everything — not assumed from a model’s reputation.

Reproducibility.Runs are deterministic and incremental: the same input yields the same output, and a re-run translates only what changed.

Economics and engines.Cost is metered in tokens per run, not per-word agency rates. The harness is engine-agnostic and already falls back to a second engine on failure — the translation engine can be swapped without touching the glossary, the memory or the gates.

v1 scope

Languages: French, Simplified Chinese, Russian. Coverage: the site’s pages and the ledger. Dossier PDF exports remain English in v1. The per-run verification record — pass rates, repairs, quarantines and metered cost — is published with each release. This page itself is translated by the loop it describes.
